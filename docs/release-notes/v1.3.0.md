## FreeDyn v1.3.0

### Bundled FreeDyn Core: v1.2.0 (unchanged)

---

### Python Bindings

**New Features**
- `ModelRelatedMatrixBuffer.create_internal_scaling_values(scaling_values)` creates an internal buffer for the scaling values of the matrix. The values are copied, so later changes to the caller's array have no effect.
- `ModelRelatedMatrixBuffer.set_scaling_from_internal_values(idx_change, value_changes)` changes single entries of this buffer and passes it to `setScalingValuesOfModelRelatedMatrix`. The new scaling is applied on the next `update_from_dll()`. This avoids allocating a new scaling array in every step of an optimization loop. Raises `MatrixError` if the buffer was not created or the DLL call fails.
- `example_03_matrix_buffer_reuse.py` shows how to change the scaling values with the internal buffer.

Idea and implementation by Philipp Zallinger.

**Breaking Changes**
- `ModelRelatedMatrixBuffer.set_index()` is removed. It switched the matrix index without checking the structure, so a matrix with more nonzeros would have overrun the buffers. Create a new `ModelRelatedMatrixBuffer` for the other matrix index instead.
